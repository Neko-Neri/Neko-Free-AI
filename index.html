📖 小白上手：如何把 API 接入常用客户端？

大部分 NewAPI / One-API 站点都遵循标准 OpenAI 接口规范。只需在对应站点注册获取 API Key (令牌) 和 Base URL (接口地址)，即可接入任意第三方客户端！

🐾 方案一：NextChat (ChatGPT-Next-Web)

点击左下角设置 ⚙️ -> 找到 自定义接口设置：

接口地址 (Base URL): 站点域名/v1 (例如: https://api.xxx.com/v1)
API Key: 填入在平台生成的 sk-xxxxxxxx 令牌
🍒 方案二：Cherry Studio (全能桌面客户端)

打开设置 -> 模型服务 -> 添加服务商选择 OpenAI：

API 域名: 填入站点 Base URL (如: https://api.catcat.top/v1)
点击“管理模型” -> 添加或拉取支持的模型 (如 gpt-4o, claude-3-5-sonnet)
💻 方案三：Cursor / VS Code (编程代码补全)

Cursor Settings -> Models -> 开启 OpenAI API Key：

Override OpenAI Base URL: 填入站点 /v1 地址
填入你生成的高额/免付费 API 密钥，保存后即可享受免费代码补全与 Agent
💬 方案四：免配置平台 (SharedChat / NexusVAI / AnyModel 等)

不想下载任何客户端？可以直接挑选本站分类为 “免配置直聊” 的站点，注册登录后在浏览器网页端直接开聊！
